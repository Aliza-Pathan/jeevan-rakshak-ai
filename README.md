# Jeevan Rakshak AI

Jeevan Rakshak AI is a smart first-aid assistant for emergency situations.

## Problem
In accidents, people don't know what to do in the first 5 minutes, which is most critical.

## Solution
An AI chatbot that gives instant, step-by-step first-aid guidance in Hindi + English with voice support.

## Features
- Instant first-aid steps
- Voice assistance
- Works on low internet
- Hindi & English support

## Tech Stack
Python, AI/ML
